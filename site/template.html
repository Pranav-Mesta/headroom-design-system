      Color

      Six ramps generated in OKLCH, so each stop has the same perceived lightness across hues. Semantic tokens map them for light and dark. A build script measures every text and background pairing and refuses to ship one below AA.

      Primitive palette

      Never used directly in components. Every stop has a name for people (Neutral Light Black) and a numeric path for code (color/neutral/900). Click a swatch to copy its hex.

      Semantic tokens

      What components consume. Each token has a light value, a dark value, and the lowest contrast it reaches against any surface.

      Finance tokens and redundant meaning

      Expenses are set in neutral ink, never red. Red-family color appears only when a limit you set is crossed. Every state also has a sign, icon or word, so switch on grayscale: nothing should become ambiguous.

      Typography

      Anek Latin carries display, titles and every amount. On phones, body and controls use SF Pro and Roboto for Dynamic Type and a native feel. On the web, Anek Latin does both jobs.

      ₹1,00,000

      0123456789 −+ ₹ % ₹1.2L

      • Native ₹ glyph. No fallback rupee with a different weight on every amount.
      • Tabular figures. Columns align and typed amounts don't jitter.
      • Slashed zero. 0 never reads as O in UPI references.
      • Narrow tabular commas. 1,00,000 stays tight, not 1 , 00 , 000.
      • Width axis 75–125. Tight amounts condense instead of shrinking.

              Grid and breakpoints

              Material 3 window size classes (600, 840, 1200) describe available space, not devices. Android, iPad split view and the web dashboard all respond to the same thresholds.

              Iconography

              Every icon comes from Not Boring Icons (stroke style): outline on a 24px grid with round caps, and a stroke that thickens with size. Category icons always sit in a 40px tile beside their name. System chrome uses SF Symbols on iOS and Material Symbols on Android.

              Motion

              Motion shows cause and effect: this tap added that amount, and this fill is your month. Amounts never count up. With Reduce Motion on, everything spatial becomes a quick crossfade.

              Animate

              • Gauge and budget fills, once per first view of a period.
              • Sheets, toasts and page transitions, in each platform's native model.
              • Press feedback within 120ms.
              • Goal reached: one deliberate celebration, never repeated.

              Never animate

              • Counting up balances. Users have to wait to learn whether they're okay.
              • Pulsing or looping warnings. Over budget is information, not a siren.
              • Parallax or decorative scroll effects.

                        Governance decisions to defend

                        Decisions to defend

                        The three Stage 1 choices a reviewer is most likely to challenge, and the evidence behind each one.

                        Why aren't expenses red?

                        Most transactions are expenses. Coloring the normal case as an alarm creates the money anxiety the product exists to reduce.

                        Red-family color is reserved for crossing a limit the user chose. Meaning is still never color-only: the − sign and the word "over" carry it for color-blind users and screen readers.

                        Why Anek Latin?

                        It was chosen by measurement, and the measurement overturned my first pick. Of 20 candidates, 9 had no ₹ glyph, and only 2 had a native ₹, tabular figures and a slashed zero.

                        Building this page exposed a fourth failure: Schibsted Grotesk widens tabular commas to figure width, so ₹18,450 rendered as ₹18 , 450. Anek Latin keeps them narrow and is the only face that passes all four tests.

                        Why show money left, not money spent?

                        "₹18,450 of room" answers the user's real question, am I okay, directly. "64% spent" makes them do the math and reads like a running score of failure.

                        The dashed clearance line is the one signature, and it is tokenised (finance/headroom, finance/clearance-line, border/dash/clearance), so the idea carries through every component and the Figma library.
