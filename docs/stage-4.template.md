# Headroom Design System · Stage 4: Patterns

> Generated by `tools/build_tokens.py` from `tools/patterns_spec.py` and this template. Edit those, never the output.
> All data is synthetic. Storyboards of every flow, built from the real components: `site/patterns.html`.

Patterns are where the system proves it holds together. Each one below names its goal and a measurable target, then gives its entry points, the flow, the rules that keep it consistent, the edge cases, and the Stage 2 components it's built from. Copy follows Stage 3.

Three threads run through all five:

1. **Clarity before alarm.** A consequence is shown before it happens ("₹1,414 left in Food after this"), as information rather than a block.
2. **Undo over "Are you sure?"** Speed for everyday actions, with protection proportional to how hard something is to reverse.
3. **Never lose the user's input.** Drafts, offline queues and optimistic saves mean a dropped network or a closed app costs nothing.
