## Token audit

"Built only from the system" is checked, not asserted. The proof page reads back every colour (text, background, border, SVG fill and stroke) and every font size each screen renders, and matches them against the token set for the current theme.

{{audit}}

**What the first audit run caught (fixed before this stage shipped):**

- `#fff` hard-coded as the label on destructive buttons and count badges → now `color/action/on-primary` (white in light mode, near-black on the lighter dark-mode coral). That also removed a dark-mode override hack.
- A one-off blue for the snackbar's Undo → now the new token `color/action/on-inverse` (blue/300 light, blue/700 dark), measured at AA on `surface/inverse`.
- Gauge headroom at 34px and spent at 20px, neither on the type scale → now `type/amount/hero` (48) and `type/amount/lg` (28).
